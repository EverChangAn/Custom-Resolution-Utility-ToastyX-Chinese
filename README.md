## 使用说明

1. 运行 `CRU.exe`（可能需要管理员权限访问注册表）
2. 选择显示器 → 编辑分辨率/扩展块 → 点击「确定」保存
3. 运行 `restart.exe`（或 `restart64.exe`）重启显卡驱动使更改生效
4. 若显示异常，进入安全模式运行 `reset-all.exe` 重置

> ⚠️ CRU 通过修改注册表 EDID 覆盖实现自定义分辨率，操作前请备份原版软件与注册表；显示异常时可用 `reset-all.exe` 或安全模式恢复。
